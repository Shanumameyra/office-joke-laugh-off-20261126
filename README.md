## The joke

> My manager said to bring my whole self to work, so I brought my resignation letter too.

## How it works

`main.py` is a deterministic program (no network, no randomness) that writes the single original one-line office joke above to `/output/entry.txt` (87 characters, within the 1–200 character gate).

```sh
python3 main.py
```
